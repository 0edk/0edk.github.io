Every symbol in several programming languages

Our basic character set, ASCII, has 95 visible characters, which include 52 letters, 10 digits, and space. In most programming languages, those respectively form identifiers (variable names and the like), numeric literals, and separations between tokens. The 32 other characters may be called symbols, and their meanings are more varied.

The table below briefly describes how each symbol is used in each of several major programming languages. Some symbols are used in bound forms with one or more other characters; these uses are also listed under each character in such forms. Languages are ordered by popularity on the TIOBE Index. You can make educated guesses for languages not listed based on which others they're similar to: C++ is much like C, C# much like Java, etc.
